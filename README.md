# Cancer Data Analysis & Predictive Modeling

## Project Overview
An end-to-end Python data analytics project exploring cancer patient demographics, risk factors, 
treatment costs, cancer severity, and survival outcomes through exploratory data analysis, inferential statistics, and machine learning.

## Objectives
- Explore cancer distribution across age and gender.
- Analyze genetic risk, smoking, and cancer severity.
- Investigate treatment costs across demographic groups and cancer stages.
- Examine survival patterns and relationships between variables.
- Build and evaluate a Random Forest model for predicting survival years.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Methodology
1. Data understanding and exploratory data analysis
2. Demographic and cancer risk-factor analysis
3. Statistical and inferential analysis
4. Treatment cost and survival analysis
5. Random Forest predictive modeling
6. Hyperparameter tuning and cross-validation

## Key Findings
- Explored differences in cancer distribution across demographic groups.
- Examined associations between genetic risk, smoking, and cancer severity.
- Investigated treatment costs and survival patterns.
- Evaluated predictive performance and model generalization.

## How to View the Project
Open the Cancer Data Analysis.ipynb notebook in this repository to explore the analysis, visualizations, and model results.

## Limitations
Findings reflect the analyzed dataset and should not be interpreted as clinical conclusions.
