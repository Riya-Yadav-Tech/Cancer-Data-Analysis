# Dataset Information

## Dataset
Global Cancer Patients (2015–2024)

## Source
Kaggle: https://www.kaggle.com/datasets/zahidmughal2343/global-cancer-patients-2015-2024

Dataset creator: zahidmughal2343

## Project Purpose
This dataset is used for exploratory data analysis, statistical analysis, visualization, and machine learning to investigate cancer-related patterns, risk factors, treatment costs, and survival outcomes.

## How to Download
1. Open the Kaggle dataset link above.
2. Download the dataset.
3. Extract the downloaded ZIP file, if applicable.
4. Place the CSV file in this data folder.
5. Update the dataset filename in the Jupyter Notebook if necessary.
